# Facebook Clone using HTML & Tailwind CSS

A Facebook-inspired user interface built using **HTML** and **Tailwind CSS** as part of my frontend learning journey. This project focuses on understanding Tailwind CSS, utility-first styling, and creating modern UI layouts through hands-on practice.

> **Note:** This project was created for learning purposes and is not a complete or fully responsive Facebook clone.
